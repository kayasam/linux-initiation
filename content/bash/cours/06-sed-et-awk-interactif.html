Scripting Shell en Bash — Chapitre 06

sed & awk

Transformer et extraire du texte en ligne de commande

# Pourquoi sed et awk ?

grep cherche des lignes. sed et awk vont plus loin : ils transforment le texte. Ces trois outils se combinent naturellement avec les tubes | et constituent la base du traitement de texte en ligne de commande Unix.
OutilRôle principalCas d'usage typique
grep Filtrer des lignes Trouver les lignes contenant "error"
sed Modifier du texte Remplacer un mot, supprimer des lignes, nettoyer un fichier
awk Extraire des colonnes et calculer Afficher la 3e colonne, calculer une somme, générer un rapport
grep '/bin/bash' /etc/passwd
|
awk -F: '{print $1, $3}'
→ Filtre les lignes bash avec grep, puis awk extrait le nom et l'UID — exemple de pipe typique.

Philosophie Unix

Chaque outil fait une chose et la fait bien. On les assemble avec | pour des traitements plus complexes. sed nettoie le texte, awk en extrait les données, grep filtre. Ensemble, ils remplacent des scripts entiers.

sed — à retenir
  • Lit ligne par ligne
  • Modifie le texte (substitution, suppression)
  • N'écrit pas dans le fichier sans -i
  • Basé sur les expressions régulières
awk — à retenir
  • Lit ligne par ligne
  • Découpe en champs ($1, $2…)
  • Peut filtrer, calculer, formater
  • Mini langage de programmation

# sed — l'éditeur de flux

sed (Stream EDitor) lit un fichier ligne par ligne et applique des transformations. Il n'ouvre jamais de fenêtre — tout se passe dans le terminal.

Important
Par défaut, sed n'écrit pas dans le fichier — il affiche le résultat sur la sortie standard. Le fichier original est intact. Pour modifier en place, utiliser -i.

Les commandes essentielles — cliquez pour les détails

s
Substitution (remplacer)
▶

La commande la plus utilisée. Remplace le texte correspondant au motif.

# Remplacer toutes les occurrences sed 's/http/https/g' config.txt # Uniquement la 1ère occurrence par ligne (sans g) sed 's/erreur/error/' app.log # Insensible à la casse (flag I) sed 's/erreur/error/gI' app.log # Supprimer un mot (remplacer par rien) sed 's/DEBUG: //g' app.log # Remplacer uniquement sur les lignes contenant "serveur" sed '/serveur/s/localhost/192.168.1.10/g' config.txt
d
Suppression de lignes
▶

Supprime les lignes correspondant au motif ou au numéro de ligne.

# Supprimer les lignes contenant "DEBUG" sed '/DEBUG/d' app.log # Supprimer les lignes vides sed '/^$/d' fichier.txt # Supprimer les commentaires (lignes commençant par #) sed '/^#/d' config.conf # Supprimer commentaires ET lignes vides (-e = plusieurs expressions) sed -e '/^#/d' -e '/^$/d' config.conf # Supprimer la première ligne (en-tête CSV) sed '1d' donnees.csv
p
Affichage sélectif (-n)
▶

-n supprime l'affichage automatique. p affiche explicitement les lignes voulues.

# Afficher seulement les lignes ERROR sed -n '/ERROR/p' app.log # Afficher les lignes 5 à 10 sed -n '5,10p' fichier.txt # Afficher uniquement la 1ère ligne sed -n '1p' fichier.txt # Afficher uniquement la dernière ligne sed -n '$p' fichier.txt
-i
Modification en place
▶

Modifie le fichier directement. Avec -i.bak, crée une sauvegarde avant.

# Modifier le fichier directement sed -i 's/ancien/nouveau/g' fichier.txt # Modifier avec sauvegarde automatique (.bak) sed -i.bak 's/ancien/nouveau/g' fichier.txt # → fichier.txt (modifié) + fichier.txt.bak (original) # Changer le port SSH (exemple réel) sed -i 's/^Port 22$/Port 2222/' /etc/ssh/sshd_config

Exemples pratiques

# Nettoyer sshd_config : retirer commentaires et lignes vides sed -e '/^#/d' -e '/^$/d' /etc/ssh/sshd_config # Extraire les erreurs d'un log sed -n '/ERROR/p' /var/log/app.log # Remplacer les virgules par des point-virgules dans un CSV sed 's/,/;/g' fichier.csv # Afficher le fichier sans la première ligne (en-tête) sed '1d' donnees.csv
Note — ^ et $
^ = début de ligne · $ = fin de ligne · /^$/ = ligne vide (début suivi immédiatement de la fin). Ce sont des ancrages d'expressions régulières POSIX.

# awk — le traiteur de colonnes

awk lit un fichier ligne par ligne et découpe chaque ligne en champs selon un séparateur. C'est l'outil idéal pour extraire des colonnes et faire des calculs. Son nom vient des initiales de ses créateurs : Aho, Weinberger, Kernighan (Bell Labs, 1977).

Fonctionnalités — cliquez pour les détails

# Afficher le 1er champ (noms d'utilisateurs) awk -F: '{print $1}' /etc/passwd # Afficher plusieurs champs awk -F: '{print $1, $7}' /etc/passwd # Avec un format personnalisé awk -F: '{print "Utilisateur : " $1 " → shell : " $7}' /etc/passwd # Numéroter les lignes awk '{print NR, $0}' fichier.txt # Afficher le dernier champ (peu importe combien il y en a) awk '{print $NF}' fichier.txt
# Filtrer par motif (comme grep) awk '/ERROR/ {print $0}' app.log # Filtrer par valeur d'un champ numérique awk -F: '$3 >= 1000 {print $1}' /etc/passwd # UID ≥ 1000 # Filtrer par valeur d'un champ chaîne awk -F'|' '$3 == "Informatique" {print $0}' employes.txt # Afficher uniquement la ligne N (NR = numéro de ligne) awk 'NR==5' fichier.txt # Afficher les lignes sauf les commentaires (!= inverse) awk '!/^#/' config.conf

BEGIN s'exécute avant de lire le fichier (en-têtes, initialisation). END s'exécute après le dernier enregistrement (totaux, rapports).

# Compter les lignes d'un fichier awk 'BEGIN {n=0} {n++} END {print "Total : " n " lignes"}' fichier.txt # En-tête + données + pied de page awk -F: 'BEGIN {print "=== Utilisateurs ==="} {print $1} END {print "=== Fin ==="}' /etc/passwd # Initialiser le séparateur dans BEGIN awk 'BEGIN {FS=":"} {print $1, $3}' /etc/passwd
# Calculer la somme d'une colonne awk -F'|' '{total += $4} END {print "Masse salariale : " total}' employes.txt # Calculer une moyenne awk '{s += $1; n++} END {print "Moyenne : " s/n}' notes.txt # Trouver le maximum awk 'BEGIN{max=0} $1>max{max=$1} END{print "Max : " max}' valeurs.txt # Afficher les 5 processus qui consomment le plus de CPU ps aux | sort -k3 -rn | awk 'NR<=5 {print $1, $3"%", $11}'

# sed + awk en pratique

Comparaison — sed vs awk

Règle pratique
sed pour modifier/nettoyer du texte (remplacer, supprimer). awk pour extraire des colonnes et faire des calculs. Les deux se combinent très bien avec des tubes.

# Quiz de révision

Testez vos connaissances — cliquez sur la bonne réponse.

1. Que fait sed 's/http/https/' (sans le flag g) ?
Sans g, sed remplace la première occurrence par ligne. Avec g (global), il remplace toutes les occurrences sur chaque ligne. Si une ligne contient http://a et http://b, seul le premier http sera remplacé sans g.
2. Comment modifier un fichier directement avec sed (sans créer un nouveau fichier) ?
sed -i (in-place) modifie le fichier directement. sed -i.bak crée une sauvegarde avant modification. La redirection sed … f > f vide le fichier avant que sed ne le lise — c'est un piège classique.
3. Que fait sed '/^$/d' ?
/^$/ est une expression régulière : ^ = début de ligne, $ = fin de ligne. ^$ = une ligne où le début est immédiatement suivi de la fin → ligne vide. Le d supprime ces lignes.
4. Dans awk -F: '{print $NF}' /etc/passwd — que contient $NF ?
NF est le nombre de champs de la ligne. $NF utilise cette valeur comme indice de champ, ce qui donne le dernier champ, quel que soit leur nombre. Dans /etc/passwd (7 champs séparés par :), $NF = $7 = le shell.
5. Quelle variable awk contient le numéro de la ligne en cours de traitement ?
NR (Number of Records) contient le numéro de la ligne en cours. $0 = la ligne entière, NF = nombre de champs, FS = séparateur de champs. Exemple : awk 'NR==1' affiche uniquement la première ligne.
6. Quand s'exécute le bloc BEGIN dans awk ?
BEGIN s'exécute avant de lire le fichier — utile pour afficher un en-tête, initialiser des variables, ou définir le séparateur FS. END s'exécute après la dernière ligne — utile pour afficher des totaux.
7. Tu veux extraire la 3e colonne d'un fichier CSV (séparé par des virgules). Quelle commande utiliser ?
awk -F, '{print $3}' est la bonne réponse. -F, définit la virgule comme séparateur de champs. Sans -F, awk utilise l'espace/tabulation comme séparateur — $3 serait le 3e mot, pas la 3e colonne CSV. cut -d, -f3 est une alternative simple pour ce cas précis.
