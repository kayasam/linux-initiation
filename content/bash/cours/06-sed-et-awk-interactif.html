Sortie standard · résultat de sed

Voir n’est pas enregistrer. Sans redirection ni option -i, sed ne change pas le fichier lu. Les guillemets simples protègent son expression du shell.


Le g se voit quand le motif revient
Ici, le motif ; est littéral. Les recherches sed utilisent des expressions régulières : tous les caractères ne sont pas de simples lettres.
Le fichier du TP
Plusieurs lignes, telles quelles
cat > stock.csv <<'EOF'
produit;categorie;quantite;prix
clavier;informatique;8;25
…
EOF
Extrait de lecture, pas un bloc à copier : le fichier complet est dans le TP. <<'EOF' fournit le texte sans expansion des variables ; EOF ferme le bloc, seul sur sa ligne. > écrit le fichier.

La loupe awk
Le séparateur donne leurs limites aux champs.
Choisis une ligne et un séparateur. Les $1, $2… désignent ici les champs d’awk, pas les arguments Bash.
Inventaire simple, sans champs cités


NR = 2
Cet atelier montre le résultat pour la ligne choisie. NR compte les lignes lues ; NR > 1 écarte l’en-tête. print sépare ici ses arguments par un espace. -F ';' découpe un format simple, pas tous les cas possibles du CSV.

Quels produits sont sous le seuil ?
Les quantités de cet atelier sont des entiers vérifiés. Sur un fichier inconnu, inspecte d’abord les premières lignes : une quantité vide ou non numérique peut fausser le filtre et les calculs.


Regarde le total grandir
total · accumulation interne0
END · résultat affiché à la fin—
Une variable awk jamais définie vaut 0 en contexte numérique : total n’a pas besoin d’une initialisation séparée. END appartient à awk ; ce n’est pas le done d’une boucle Bash.
