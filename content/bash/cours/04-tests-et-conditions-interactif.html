Code renvoyé par grep
-q garde la recherche silencieuse ; -x exige une ligne entière.
Message de la branche choisie
grep peut renvoyer 1 (aucune correspondance) ou 2 (erreur ici). if prend else dans les deux cas. -q ne masque pas les messages d’erreur.


Deux vérifications avec &&
[[ -f "billet.txt" && -r "billet.txt" ]]
Les deux tests doivent réussir. Si -f échoue, Bash n’a pas besoin d’évaluer -r.

Le menu de la station
Une valeur. Plusieurs motifs possibles.
case choisit la première branche qui correspond. Les synonymes peuvent partager la même action.
Saisie simulée


radio | phonie)Canal radio ouvert;; termine cette branche.
reserve | stock)Reserve disponibleDeux mots, une seule action.
*)Choix inconnuLe motif * récupère les autres cas.
Le | entre les motifs de case regroupe des alternatives. Ce n’est pas un tube entre commandes. esac ferme la structure.


Un motif pour valider la forme
case "$choix" in
    [0-9]) echo "Chiffre accepte : $choix" ;;
    *) echo "Ce n'est pas un chiffre" >&2 ;;
esac
7 convient ; 12, -1, une espace ou une valeur vide ne conviennent pas. [0-9] décrit un seul caractère, pas un entier de longueur quelconque.
Deux destinations avec ||
[[ "$destination" == "Orion" ||
   "$destination" == "Vega" ]]
Un seul succès suffit. Si le premier test réussit, Bash ne teste pas le second.
