Le robot copieur
Le motif sélectionne. Le test fait le tri.
Le robot parcourt "$source"/*.txt, garde les fichiers ordinaires et compte les copies réussies. Les originaux restent en place.
Aucun fichier réel modifié


compteur=0
for fichier in "$source"/*.txt; do
    if [[ ! -f "$fichier" ]]; then continue; fi
    if ! cp -- "$fichier" "$destination/"; then
        echo "Copie impossible : $fichier" >&2
        exit 1
    fi
    compteur=$((compteur + 1))
done
Le lancement vérifie d’abord les arguments et le dossier source, puis crée la destination avec mkdir -p --. Le motif est ensuite développé. Ordre des noms fixé pour cette démo.

Les guillemets au bon endroit. "$source" protège le dossier ; le * reste hors des guillemets pour chercher les noms. "$fichier" garde journal radio.txt en un seul argument. -- termine les options de cp.
Réglages Bash habituels : nullglob et failglob désactivés. Sans correspondance, le motif reste littéral ; -f l’écarte. Une nouvelle copie remplace le fichier de même nom : ce n’est pas un historique de sauvegarde.
