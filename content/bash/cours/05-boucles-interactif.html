# La boucle for

La boucle for exécute une série de commandes pour chaque élément d'une liste. C'est la boucle la plus utilisée en bash, aussi bien dans les scripts qu'en ligne de commande directe.

En français : "POUR chaque élément DE la liste, FAIRE … FIN"

Anatomie — cliquez sur chaque partie

1
for jour in lundi mardi mercredi jeudi vendredi ; do
for variable in liste ; do
— for : "pour chaque"
— jour : nom de la variable qui prendra chaque valeur (libre choix)
— in lundi mardi… : la liste à parcourir, séparée par des espaces
— do : "faire" — ouvre le bloc à répéter. Le ; avant do peut être remplacé par un retour à la ligne.
2
echo "Aujourd'hui : $jour"
Corps de la boucle — les commandes à exécuter à chaque tour. La variable $jour prend successivement chaque valeur de la liste : lundi, puis mardi, etc. L'indentation (4 espaces) n'est pas obligatoire mais indispensable pour la lisibilité.
3
done
done — ferme le bloc de la boucle. Obligatoire. Bash retourne ensuite à la ligne for pour l'itération suivante, jusqu'à épuisement de la liste.
↑ Cliquez sur une ligne pour voir son rôle

Variantes — cliquez pour voir les exemples

📝 Liste statique ▶
for jour in lundi mardi mercredi jeudi vendredi ; do echo "Aujourd'hui : $jour" done

La liste est écrite directement dans la commande, séparée par des espaces.

🔢 Plage de nombres {1..10} ▶
# Plage simple for i in {1..5} ; do echo "Itération $i" done # Plage avec pas for i in {0..10..2} ; do echo $i # 0 2 4 6 8 10 done # Compte à rebours for i in {5..1} ; do echo $i && sleep 1 done echo "Décollage !"
⚙️ Style C — (( )) ▶
# Syntaxe proche du C for (( i=0 ; i<5 ; i++ )) ; do echo $i done # 0 1 2 3 4 # Compte à rebours style C for (( i=5 ; i>=1 ; i-- )) ; do echo $i && sleep 1 done

Utile quand on a besoin d'un compteur avec initialisation, condition et pas personnalisés.

📁 Fichiers par glob ▶
# Bonne pratique : glob direct for fichier in *.txt ; do echo "Traitement de $fichier" done # À éviter : $(ls *.txt) # → casse si les noms contiennent des espaces

Le glob (*.txt) est plus sûr que $(ls *.txt) car il gère correctement les espaces dans les noms de fichiers.

💻 Résultat de commande ▶
# Utilisateurs du système for user in $(cut -d: -f1 /etc/passwd) ; do echo $user done

La substitution de commande $(…) génère la liste à la volée. Attention aux espaces dans les valeurs.

↔️ Sur une ligne ▶
# Pratique en ligne de commande directe for i in {1..3} ; do echo "ligne $i" ; done # Créer 5 fichiers en une commande for i in {1..5} ; do touch "fichier${i}.txt" ; done

# while & until

while et until exécutent un bloc de commandes de façon répétée en fonction d'une condition, quand on ne connaît pas à l'avance le nombre d'itérations.

Comparaison while vs until

⟳ while — "tant que"
Continue tant que la condition est VRAIE. S'arrête quand elle devient fausse.
while [[ "$c" -lt 5 ]] ; do echo $c (( c++ )) done
⟳ until — "jusqu'à ce que"
Continue tant que la condition est FAUSSE. S'arrête quand elle devient vraie. L'inverse exact de while.
until [[ -f "/tmp/signal" ]] ; do echo "En attente…" sleep 2 done echo "Signal reçu !"
StructureContinue tant que…S'arrête quand…
whilela condition est vraie (0)la condition devient fausse
untilla condition est faussela condition devient vraie (0)

Exemples while

# Compteur classique compteur=0 while [[ "$compteur" -lt 5 ]] ; do echo "Compteur : $compteur" (( compteur++ )) done
# Saisie utilisateur jusqu'à réponse valide reponse="" while [[ "$reponse" != "oui" && "$reponse" != "non" ]] ; do read -p "Continuer ? (oui/non) : " reponse done echo "Vous avez répondu : $reponse"
Danger — boucle infinie
Oublier d'incrémenter le compteur crée une boucle infinie. Pour en sortir : Ctrl+C.
c=0 while [[ "$c" -lt 5 ]] ; do echo $c # (( c++ )) ← oublié → boucle infinie ! done

Lire un fichier ligne par ligne

La combinaison while read est le moyen idiomatique de traiter un fichier :

while read -r ligne ; do echo "→ $ligne" done < /etc/hosts
# Afficher uniquement les utilisateurs bash while read -r ligne ; do if [[ "$ligne" == *"/bin/bash" ]] ; then echo "$ligne" | cut -d: -f1 fi done < /etc/passwd
Note — toujours read -r
Utiliser systématiquement read -r pour lire un fichier. Sans -r, bash interprète les antislashs présents dans le fichier comme des caractères spéciaux, ce qui peut corrompre la valeur lue.

# Expressions arithmétiques

Bash évalue les expressions arithmétiques avec $(( expression )). Attention : bash ne gère que les entiers. Pour des calculs avec décimaux, il faut utiliser la commande externe bc.

Opérateurs

+
Addition
$(( a + b ))
-
Soustraction
$(( a - b ))
*
Multiplication
$(( a * b ))
/
Division entière
$(( a / b ))
%
Modulo
$(( a % b ))
**
Puissance
$(( 2**8 ))

Calculatrice interactive

Tester les opérateurs arithmétiques

a + b13
a - b7
a * b30
a / b3
a % b1
a ** b1000

Modifier une variable

compteur=0 # Affectation classique compteur=$(( compteur + 1 )) # Raccourcis avec (( )) — pas besoin de $ (( compteur++ )) # +1 (( compteur-- )) # -1 (( compteur += 5 )) # +5 (( compteur *= 2 )) # ×2
Entiers uniquement
$(( 10 / 3 )) retourne 3, pas 3.33. La division est entière. Pour des décimaux, utiliser bc :
echo "scale=2; 10 / 3" | bc # 3.33 echo "scale=4; sqrt(2)" | bc # 1.4142

Utilisation dans les boucles

# Afficher les carrés de 1 à 5 for i in {1..5} ; do echo "$i² = $(( i * i ))" done # Afficher les nombres pairs de 1 à 20 for i in {1..20} ; do [[ $(( i % 2 )) -eq 0 ]] && echo $i done

# break & continue

Ces deux commandes permettent de contrôler le déroulement d'une boucle depuis l'intérieur du bloc.

Visualisation — choisissez le comportement

Boucle sur {1..6} — que se passe-t-il ?

Affiché
Sauté (continue)
Arrêt (break)

break — sortir de la boucle

for i in {1..10} ; do if [[ "$i" -eq 5 ]] ; then echo "Arrêt à $i" break fi echo $i done # Affiche : 1 2 3 4 Arrêt à 5
# break dans un while — chercher le premier fichier .conf for f in /etc/* ; do if [[ "$f" == *.conf ]] ; then echo "Premier .conf : $f" break fi done

continue — passer à l'itération suivante

# Afficher uniquement les nombres impairs for i in {1..6} ; do if [[ $(( i % 2 )) -eq 0 ]] ; then continue # on saute les pairs fi echo $i done # Affiche : 1 3 5
# Traiter des fichiers — sauter ceux qui n'existent pas for f in "$@" ; do [[ -f "$f" ]] || { echo "Ignoré : $f" >&2 ; continue ; } echo "Traitement de $f" done
Résumé
break : sort immédiatement de la boucle en cours — le reste du script continue après done.
continue : saute le reste du bloc courant et passe directement à l'itération suivante.

Exercices — exemples complets

Compte à rebours (for) :

#!/usr/bin/env bash set -euo pipefail for i in {5..1} ; do echo $i sleep 1 done echo "Décollage !"

Créer des fichiers en série :

#!/usr/bin/env bash set -euo pipefail dossier="$1" [[ -d "$dossier" ]] || { echo "Erreur" >&2 ; exit 1 ; } for i in {1..5} ; do touch "$dossier/fichier${i}.txt" echo "Créé : fichier$i.txt" done

# Quiz de révision

Testez vos connaissances — cliquez sur la bonne réponse.

1. Que génère for i in {3..7} ; do echo $i ; done ?
{3..7} génère la séquence 3 4 5 6 7. La boucle s'exécute 5 fois, et echo $i affiche chaque valeur sur une nouvelle ligne. C'est l'une des formes les plus pratiques pour les plages numériques.
2. Quelle est la différence fondamentale entre while et until ?
while : continue tant que la condition est vraie (0). until : continue tant que la condition est fausse, s'arrête quand elle devient vraie. Ce sont des inverses exacts — les deux vérifient la condition avant chaque tour.
3. Quelle est la bonne façon d'itérer sur des fichiers .log pour éviter les problèmes avec les espaces dans les noms ?
Le glob direct for f in *.log est la bonne pratique. $(ls *.log) découpe le résultat sur les espaces : un fichier nommé mon log.log serait vu comme deux arguments séparés. Le glob bash respecte nativement les espaces dans les noms.
4. Que retourne $(( 7 % 3 )) ?
% est le modulo — le reste de la division entière. 7 ÷ 3 = 2 reste 1. Le modulo est très utile pour tester si un nombre est pair (n % 2 == 0) ou pour des cycles.
5. Dans une boucle for i in {1..10}, que fait continue quand i=5 ?
continue saute le reste du corps de la boucle pour l'itération courante et passe à la suivante. La boucle continue donc normalement pour i=6, 7, 8, 9, 10. C'est break qui sortirait de la boucle.
6. Quelle ligne est indispensable dans un while avec compteur pour éviter une boucle infinie ?
Si le compteur n'évolue jamais, la condition reste toujours vraie et la boucle ne s'arrête jamais. Il faut toujours incrémenter (ou modifier) la variable de la condition : (( compteur++ )). Pour sortir d'une boucle infinie : Ctrl+C.
7. Pourquoi utiliser read -r pour lire un fichier ligne par ligne ?
Sans -r (raw), bash interprète les séquences \n, \t, \\ etc. trouvées dans les lignes lues. Avec -r, la ligne est lue telle quelle. C'est la bonne pratique systématique pour la lecture de fichiers.
