La mémoire de la station

Range une valeur. Retrouve-la par son nom.

Une variable associe un nom à une valeur. Modifie le prénom et observe les trois étapes.

Atelier simulé

1. Affecter, c’est ranger

Variable · prenomMila

Le nom reste prenom. Seule la valeur change. Pas de $ pour affecter, aucun espace autour de =.

2. Lire, c’est remplacer

prenom→$prenom→la valeur
Exemple à reproduire dans Bash
Les guillemets doubles protègent la valeur lors de sa lecture. Tu vas voir pourquoi à l’étape 02.


Le piège à éviter
Quelle ligne range correctement Mila ?
Choisis une écriture pour voir l’explication.
Un nom commence par une lettre ou un souligné, puis utilise lettres, chiffres ou soulignés. prenom et PRENOM sont différents.


Des accolades pour viser juste
mission="orion"
fichier="${mission}_rapport.txt"
→ orion_rapport.txt
Les accolades délimitent mission avant le suffixe _rapport.txt.
Un nom de secours
echo "Nom affiche : ${surnom:-visiteur}"
Un secours, pas une affectation. Si surnom est vide ou absent, on affiche visiteur. La variable garde sa valeur d’origine.

$(commande) · sortie simulée
Demande à la machine
commande→sortie→variable
Résultat d’exemple
La date de cet exemple est fixe. Dans ton terminal, date renverra le jour de l’exécution. "$machine" lit ; $(hostname) exécute une commande.


$((calcul)) · réserve d’énergie
Combien d’énergie pour Orion ?
Chaque batterie fournit 25 unités. Dans $((...)), Bash interprète les valeurs comme des entiers.
Opérateurs : +, -, *, /, %. La division est entière. On vérifiera les saisies libres avant de calculer au chapitre 04.








Les deux cabines · le retour
Un nouveau Bash ne reçoit pas tout.
Le parent crée NOM_STATION. Fais varier export, puis lance le Bash enfant et observe ce qu’il reçoit.
Simulation pas à pas


Shell parent
NOM_STATION="Orion"
Bash enfant · bash -c
Pas encore lancéIl attend son départ.
Observe les guillemets simples de bash -c. Ils transmettent le texte à l’enfant, qui lit la variable. Des guillemets doubles laisseraient le parent remplacer le $ avant le lancement.


env ou set : qui apparaît ?
locale_seule="Vega"
export EXPORTEE="Orion"
Extrait simulé. set affiche aussi les fonctions du shell. Pour chercher : env | grep EXPORTEE.
Déjà là avant toi
HOME désigne ton dossier personnel, par exemple /home/stagiaire.
Choisis les minuscules pour tes variables. Les noms système sont souvent en majuscules. Garde HOME et PATH pour leur rôle.
Une variable disparaît avec son processus. export transmet aux programmes lancés ensuite ; les modifications d’un enfant ne remontent pas vers le parent.
