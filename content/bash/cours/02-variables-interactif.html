Chapitre 02 — syntaxe, portée, substitution, read

# Syntaxe des variables

Une variable, c'est un nom associé à une valeur. C'est le mécanisme de base pour stocker et réutiliser une information dans un script ou dans le shell.

Affectation

L'affectation se fait avec =, sans espace avant ni après :

ma_variable=Bonjour ville="Paris" nombre=42
Erreur classique
Un espace autour du = provoque une erreur — bash interprète alors le nom comme une commande.
ma_variable = Bonjour # ERREUR : bash cherche une commande "ma_variable" ma_variable=Bonjour # CORRECT

Lecture (référencement)

Pour accéder au contenu, on place $ devant le nom :

echo $ma_variable # Bonjour echo $ville # Paris

Désambiguation avec ${}

Quand le nom de la variable est accolé à d'autres caractères, les accolades délimitent clairement le nom :

unite=gramme echo "cette pomme pèse 2 $unite" # cette pomme pèse 2 gramme echo "cette pomme pèse 2 $unites" # cette pomme pèse 2 ← variable vide ! echo "cette pomme pèse 2 ${unite}s" # cette pomme pèse 2 grammes ✓
Bonne pratique
Utiliser ${} dès que la variable est suivie d'autres caractères pour éviter toute ambiguïté.

Guillemets — comportement du $

Le type de guillemets change tout. Cliquez pour voir l'effet :

nom=Samuel echo "Bonjour $nom"
Bonjour Samuel

Les guillemets doubles interprètent $, ` et \. La variable est remplacée par sa valeur. À utiliser pour les chaînes qui contiennent des variables.

nom=Samuel echo 'Bonjour $nom'
Bonjour $nom

Les guillemets simples sont littéraux : aucune substitution n'a lieu. $nom est affiché tel quel. À utiliser pour des chaînes fixes.

fichier="mon fichier.txt" ls $fichier # PROBLÈME ls "$fichier" # CORRECT
ls: cannot access 'mon': No such file or directory

Sans guillemets, bash découpe la valeur sur les espaces : mon fichier.txt devient deux arguments. Toujours citer les variables dont la valeur peut contenir des espaces.

# Portée des variables

Locale vs exportée

Une variable locale n'existe que dans le shell courant. Elle n'est pas transmise aux sous-shells. Cliquez pour voir la différence :

Shell parent
ma_variable="local"
echo $ma_variable # local ✓
bash # ouvre un sous-shell
Sous-shell (bash enfant)
echo $ma_variable # (vide) — variable non transmise
exit
Shell parent
export MA_VARIABLE="environnement"
echo $MA_VARIABLE # environnement ✓
bash # ouvre un sous-shell
Sous-shell (bash enfant)
echo $MA_VARIABLE # environnement ✓ transmise !
exit
# Exporter une nouvelle variable export MA_VARIABLE="valeur" # Exporter une variable déjà définie compteur=0 export compteur # Repasser en locale (retirer l'export) export -n MA_VARIABLE # Supprimer une variable unset ma_variable # sans le $

Lister les variables

env # toutes les variables d'environnement (NOM=valeur) printenv # identique à env printenv PATH HOME # affiche des variables précises (sans $) export -p # format declare -x NOM="valeur" set | less # toutes les variables ET fonctions du shell

Modifier le PATH

Attention
Ne jamais remplacer le PATH entier. Toujours ajouter avec $PATH: au début ou à la fin. Sinon les commandes système (ls, cd…) deviennent introuvables.
# Afficher le PATH actuel echo $PATH # /usr/local/bin:/usr/bin:/bin # Ajouter un dossier pour la session courante export PATH="$PATH:/opt/mon-outil/bin" # Rendre la modification permanente → dans ~/.bashrc echo 'export PATH="$PATH:/opt/mon-outil/bin"' >> ~/.bashrc source ~/.bashrc
Variable d'env ponctuelle
On peut passer une variable d'environnement pour une seule commande, sans modifier le shell :
LANG=C date # date en anglais pour cette commande seulement LANG=fr_FR.UTF-8 date # date en français

# Opérations sur les variables

Substitution de commande $(…)

On peut stocker le résultat d'une commande dans une variable :

os=$(uname -o) echo $os # GNU/Linux date_du_jour=$(date +%Y-%m-%d) echo $date_du_jour # 2026-05-13 nb_users=$(wc -l < /etc/passwd) echo "Il y a $nb_users utilisateurs sur ce système"
Note — Backticks obsolètes
Tu peux rencontrer l'ancienne syntaxe avec des guillemets inversés : os=`uname -o`. Cette notation est obsolète — préférer toujours $(). Elle est plus lisible et supporte l'imbrication : $(echo $(date)).

Longueur d'une variable ${#…}

os=$(uname -o) echo $os # GNU/Linux echo ${#os} # 9 mot="bonjour" echo ${#mot} # 7

Remplacement conditionnel

Les accolades permettent de définir une valeur de substitution selon qu'une variable est définie ou non. Cliquez sur un opérateur pour voir les détails :

${variable:-texte}
Valeur par défaut si vide
Retourne texte si la variable est vide ou inexistante, sinon retourne la valeur de la variable. Ne modifie pas la variable.
echo $nom # (vide) echo ${nom:-Camille} # Camille echo $nom # (toujours vide)
Très utilisé dans les scripts pour gérer les arguments manquants.
${variable:=texte}
Valeur par défaut + affectation
Comme :- mais affecte aussi la valeur à la variable si elle est vide.
echo ${nom:=Camille} # Camille echo $nom # Camille ← affecté !
${variable:+texte}
Texte alternatif si définie
Retourne texte si la variable est définie et non vide, sinon retourne rien. L'inverse de :-.
nom=Samuel echo ${nom:+"Valeur définie"} # Valeur définie unset nom echo ${nom:+"Valeur définie"} # (vide)
${variable:?texte}
Erreur si vide → arrêt
Si la variable est vide ou inexistante, affiche texte sur stderr et quitte le script avec une erreur. Utile pour valider les variables obligatoires.
unset nom echo ${nom:?Variable non définie} # bash: nom: Variable non définie → arrêt
# Exemple pratique : argument avec valeur par défaut cible=${1:-/tmp} # $1 ou /tmp si aucun argument echo "Cible : $cible" # Valider qu'une variable obligatoire est définie fichier=${1:?Usage: script.sh <fichier>}

# Lire l'entrée utilisateur — read

La commande read lit une ligne depuis l'entrée standard (clavier ou pipe) et la stocke dans une variable. C'est le moyen principal de rendre un script interactif.

Syntaxe de base

# Lecture simple → stockée dans la variable "reponse" read reponse echo "Tu as saisi : $reponse" # Sans nom de variable → stockée dans $REPLY (variable par défaut) read echo "$REPLY"

Options de read — cliquez pour les détails

read -p "message" var basique ▶

Affiche un prompt avant d'attendre la saisie. Le flag -p (prompt) évite d'avoir à faire un echo séparé.

read -p "Ton prénom : " prenom echo "Bonjour, $prenom !"
read -s var sécurité ▶

Mode silencieux (silent) : les caractères tapés ne s'affichent pas à l'écran. Indispensable pour les mots de passe.

read -s -p "Mot de passe : " mdp echo # retour à la ligne (car le \n n'est pas affiché) echo "Mot de passe saisi."
read -n N var contrôle ▶

Lit exactement N caractères et s'arrête sans attendre Entrée. Utile pour des confirmations à un seul caractère (o/n).

read -n 1 -p "Continuer ? (o/n) : " choix echo # retour à la ligne echo "Tu as choisi : $choix"
read -t N var contrôle ▶

Timeout : abandonne après N secondes si aucune saisie. Le code de retour est 1 si le timeout est atteint.

read -t 10 -p "Répondez en 10 s : " rep # si timeout → $? vaut 1
read var1 var2 var3 multi-vars ▶

Lit plusieurs variables en une fois. La saisie est découpée sur les espaces (IFS). Le dernier nom récupère le reste de la ligne.

read prenom nom # saisie : Samuel Guillard echo $prenom # Samuel echo $nom # Guillard
read -r var basique ▶

Désactive l'interprétation des antislashs (raw mode). Sans -r, un \n tapé serait interprété comme un retour à la ligne. Bonne pratique : utiliser read -r par défaut dans les scripts.

read -r ligne # lecture brute sans interprétation

Exemple complet — script interactif

#!/bin/bash read -p "Prénom : " prenom read -p "Nom : " nom read -s -p "Mot de passe : " mdp echo # retour à la ligne après le mot de passe silencieux echo "Bienvenue, $prenom $nom !" echo "Longueur du mot de passe : ${#mdp} caractères"

read depuis un pipe ou un fichier

# Lire une ligne depuis un fichier avec redirection read premiere_ligne < /etc/hostname echo $premiere_ligne # Lire toutes les lignes d'un fichier dans une boucle while read -r ligne; do echo "→ $ligne" done < /etc/hosts
Note — IFS et read
IFS (Internal Field Separator) détermine comment read découpe la saisie. On peut le changer temporairement pour utiliser un autre séparateur :
# Lire un fichier CSV (séparé par des virgules) IFS=',' read -r champ1 champ2 champ3 <<< "Paris,Lyon,Marseille" echo $champ1 # Paris echo $champ2 # Lyon
Récap des flags à retenir
-p prompt · -s silencieux · -r raw (à mettre par défaut dans les scripts) · -n N N caractères · -t N timeout N secondes

# Quiz de révision

Testez vos connaissances — cliquez sur la bonne réponse.

1. Quelle ligne provoque une erreur dans bash ?
Les espaces autour du = font que bash interprète ma_variable comme une commande avec les arguments = et Bonjour. L'affectation doit toujours être écrite sans espace : ma_variable=Bonjour.
2. nom="Samuel". Que s'affiche avec echo 'Bonjour $nom' (guillemets simples) ?
Les guillemets simples sont littéraux : aucune substitution n'a lieu. $nom est affiché tel quel. Pour que la variable soit interprétée, il faut des guillemets doubles : "Bonjour $nom".
3. Quelle commande rend une variable visible dans les scripts appelés depuis le shell courant ?
export marque la variable comme variable d'environnement : elle est transmise à tous les processus enfants (scripts, commandes). Une variable locale n'est visible que dans le shell courant.
4. Comment stocker le résultat de la commande "date" dans la variable "auj" ?
$(commande) est la substitution de commande : bash exécute la commande et remplace $(…) par son résultat. L'ancienne syntaxe avec backticks (`date`) fonctionne aussi mais est obsolète.
5. nom="" (variable vide). Que retourne echo ${nom:-Camille} ?
${:-} retourne la valeur de remplacement si la variable est vide ou inexistante, mais ne modifie pas la variable. Après cet echo, $nom est toujours vide. Pour affecter aussi, il faudrait ${nom:=Camille}.
6. Quel flag de read masque les caractères tapés au clavier (utile pour un mot de passe) ?
read -s active le mode silencieux (silent) : les caractères tapés ne s'affichent pas à l'écran. On l'utilise systématiquement pour la saisie de mots de passe. Penser à ajouter echo après pour revenir à la ligne.
7. mot="hello". Que retourne echo ${#mot} ?
${#variable} retourne la longueur (nombre de caractères) de la valeur. "hello" fait 5 caractères → affiche 5.
