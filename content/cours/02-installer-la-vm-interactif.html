Linux Initiation

02 — Installer la VM Debian

Créer une machine virtuelle avec VirtualBox et installer Debian pas à pas.

Qu'est-ce qu'une machine virtuelle ?

Une machine virtuelle (VM) est un ordinateur simulé à l'intérieur d'un ordinateur réel. Elle s'exécute dans une fenêtre, comme n'importe quel autre logiciel, mais dispose de son propre système d'exploitation, son propre disque dur (virtuel), sa propre carte réseau…

Note — Analogie
Imaginez un appartement indépendant à l'intérieur d'une maison. L'appartement a sa propre porte, sa propre cuisine, sa propre électricité — mais il reste à l'intérieur de la maison principale. Si l'occupant de l'appartement casse quelque chose, cela n'abîme pas la maison principale.

Pourquoi utiliser une VM ?

  • Tout casser sans risque — si vous faites une fausse manipulation dans la VM, votre vrai ordinateur n'est pas affecté
  • Pas besoin d'un 2e ordinateur — une VM s'exécute sur votre machine actuelle
  • Isolation totale — la VM est séparée de votre système principal ; ce qui se passe dans la VM reste dans la VM
  • Instantanés — vous pouvez sauvegarder l'état de la VM à tout moment et revenir en arrière si besoin

VirtualBox

VirtualBox est le logiciel de virtualisation que nous utilisons dans cette formation. Il est :

  • Gratuit et open source (développé par Oracle)
  • Multiplateforme : fonctionne sur Windows, macOS et Linux
  • Facile à prendre en main avec une interface graphique claire
VirtualBox — virtualbox.org — Gratuit
Tip — Version Debian
Pour cette formation, nous installons Debian 12 (Bookworm) ou Debian 13 (Trixie) selon votre formateur. L'installation est identique dans les deux cas.

Créer la VM dans VirtualBox — Étapes interactives

Cliquez sur chaque étape pour voir les détails et les paramètres à saisir.

1
Nouveau — Nommer la VM ▶

Dans VirtualBox, cliquez sur Nouveau (bouton bleu en haut). Renseignez :

Nom :Debian-Formation
Dossier :(laisser par défaut)
Type :Linux
Version :Debian (64-bit)

Si vous tapez "Debian" dans le nom, VirtualBox détecte automatiquement le type et la version.

2
Mémoire vive (RAM) ▶

Définissez la quantité de RAM allouée à la VM :

Minimum :2 048 Mo (2 Go)
Recommandé :4 096 Mo (4 Go)
Attention
N'allouez jamais plus de la moitié de la RAM de votre machine physique. Si votre PC a 8 Go de RAM, ne dépassez pas 4 Go pour la VM. Sinon, votre PC hôte risque de manquer de mémoire.
3
Disque dur virtuel ▶

Créez un nouveau disque dur virtuel pour la VM :

Action :Créer un disque dur virtuel maintenant
Type de fichier :VDI (VirtualBox Disk Image)
Allocation :Dynamique (grandit au besoin)
Taille :20 Go minimum

Un disque dynamique n'occupe sur votre vrai disque que l'espace réellement utilisé. Pratique !

4
Configuration réseau ▶

Après la création de la VM, allez dans Configuration → Réseau :

Carte 1 :Activée — Mode NAT

Le mode NAT (Network Address Translation) permet à la VM d'accéder à Internet via la connexion de votre PC hôte, sans configuration complexe. C'est le mode par défaut et il convient parfaitement pour cette formation.

Tip
Si vous avez besoin d'accéder à la VM depuis votre PC hôte (SSH), ajoutez une Carte 2 en mode Host-Only.

Démarrer l'installation

Au premier démarrage de la VM, VirtualBox vous demandera un fichier ISO à utiliser comme "CD d'installation". Sélectionnez le fichier debian-xx.x.x-amd64-netinst.iso que vous avez téléchargé depuis debian.org.

Tip
Choisissez l'option "Install" (pas "Graphical Install") pour vous familiariser avec l'installeur texte de Debian. C'est plus rapide et très guidé.

Tip — Durée
L'installation complète dure entre 10 et 20 minutes selon la vitesse de votre connexion Internet (Debian télécharge des paquets pendant l'installation). Soyez patient !
Attention — Mot de passe root
Le mot de passe root est le mot de passe du compte administrateur du système. Notez-le sur papier maintenant. Si vous l'oubliez, récupérer l'accès est complexe.

Premier démarrage après installation

Une fois l'installation terminée, Debian redémarre automatiquement. L'écran de connexion GNOME apparaît.

Se connecter

  • Cliquez sur votre nom d'utilisateur (pas root !)
  • Saisissez votre mot de passe utilisateur
  • Le bureau GNOME s'affiche
Danger — Ne jamais travailler en root au quotidien
Le compte root a tous les pouvoirs sur le système, sans aucune restriction. Une seule commande mal tapée peut supprimer des fichiers système critiques ou rendre le système inutilisable. Travaillez toujours avec votre compte utilisateur normal et utilisez sudo uniquement quand c'est nécessaire.

Tip — Instantanés (snapshots)
Avant chaque TP important, prenez un instantané de votre VM. Si quelque chose tourne mal, vous pourrez revenir à cet état propre en quelques secondes. C'est l'un des grands avantages des machines virtuelles !

Vérifier la connexion Internet

Ouvrez un terminal dans Debian (Activités → Terminal) et tapez :

ping -c 3 8.8.8.8

Si vous obtenez des réponses, votre VM est connectée à Internet. Bravo !
