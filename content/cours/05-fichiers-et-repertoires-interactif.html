Module 05

Fichiers et Répertoires

Créer, copier, déplacer, supprimer et rechercher

Créer fichiers et dossiers

Sous Linux, tout est fichier : les documents, les programmes, mais aussi les périphériques et les paramètres système.

Analogie

Les dossiers sont comme des tiroirs étiquetés dans un classeur : ils permettent d'organiser les fichiers et de retrouver facilement ce qu'on cherche.

mkdir — Créer un dossier

mkdir projets                     # crée le dossier "projets"
mkdir projets/linux               # crée "linux" dans "projets"
mkdir -p projets/linux/cours      # crée toute la hiérarchie d'un coup
Note — Option -p

L'option -p (parents) crée tous les dossiers intermédiaires si ils n'existent pas encore. Sans -p, mkdir échoue si le dossier parent n'existe pas.

touch — Créer un fichier vide

touch notes.txt                   # crée un fichier vide (ou met à jour sa date)
touch a.txt b.txt c.txt           # crée plusieurs fichiers d'un coup

echo et redirection — Écrire dans un fichier

echo "Bonjour" > notes.txt        # écrit dans le fichier (écrase le contenu)
echo "Ligne 2" >> notes.txt       # ajoute à la fin sans écraser
cat notes.txt                     # vérifie le contenu
OpérateurEffet
>Redirige la sortie vers un fichier — écrase si le fichier existe
>>Redirige la sortie — ajoute à la fin sans écraser

cp — Copier

cp notes.txt notes-sauvegarde.txt     # copie et renomme
cp notes.txt /tmp/                    # copie dans /tmp
cp -r projets/ /tmp/                  # copie un dossier entier (-r récursif)
Attention

Sans -r (récursif), cp ne peut pas copier un dossier — il retourne une erreur. Pensez toujours à -r pour les dossiers.

mv — Déplacer ET renommer

mv notes.txt documents/               # déplace dans le dossier "documents"
mv notes.txt rapport.txt              # renomme (même dossier)
mv projets/ /home/work/               # déplace un dossier entier
Astuce

mv fait à la fois déplacer et renommer. Si la destination est un dossier existant, le fichier est déplacé dedans. Sinon, il est renommé.

Récapitulatif cp vs mv

CommandeRésultatFichier source
cp a.txt b.txta.txt copié en b.txta.txt reste intact
mv a.txt b.txta.txt renommé en b.txta.txt disparaît
cp -r dir/ dest/dir/ copié dans dest/dir/ reste intact
mv dir/ dest/dir/ déplacé dans dest/dir/ disparaît de l'emplacement original

rm — Supprimer

rm notes.txt                  # supprime un fichier
rm a.txt b.txt c.txt          # supprime plusieurs fichiers
rmdir projets/                # supprime un dossier vide
rm -r projets/                # supprime un dossier et tout son contenu
DANGER — rm est définitif

Il n'y a pas de corbeille sous Linux. Une fois supprimé avec rm, un fichier est irrécupérable. Vérifiez toujours ce que vous tapez avant d'appuyer sur Entrée.

La commande rm -rf / peut détruire l'intégralité du système. Ne jamais l'exécuter.

Wildcards — Jokers

Les jokers permettent de cibler plusieurs fichiers en une seule commande.

JokerSignificationExempleCorrespond à
*N'importe quelle suite de caractères*.txtnotes.txt, rapport.txt…
?Un seul caractère quelconquefichier?.txtfichier1.txt, fichierA.txt…
[abc]Un caractère parmi la listefichier[123].txtfichier1.txt, fichier2.txt, fichier3.txt

Exemples pratiques

ls *.txt                      # lister tous les fichiers .txt
rm rapport_*.txt              # supprimer tous les rapports
cp *.conf /tmp/               # copier tous les fichiers de config dans /tmp
ls fichier?.txt               # lister fichier1.txt, fichierA.txt...

find — Rechercher des fichiers

La commande find parcourt une arborescence pour trouver des fichiers selon différents critères.

find /home -name "notes.txt"          # recherche par nom exact
find /home -name "*.txt"              # tous les fichiers .txt dans /home
find /etc -name "*.conf" -type f      # fichiers .conf uniquement (pas les dossiers)
find /tmp -mtime -1                   # modifiés dans les dernières 24 heures
OptionSignificationExemple
-nameNom du fichier (sensible à la casse)-name "*.log"
-inameNom (insensible à la casse)-iname "*.TXT"
-type fFichiers uniquement
-type dDossiers uniquement
-mtime -NModifié il y a moins de N jours-mtime -7
-size +NPlus grand que N (k=Ko, M=Mo)-size +100k
Astuce

Pour rechercher dans tout le système, utilisez find / ... mais attendez-vous à voir des messages d'erreur pour les dossiers non accessibles. Ajoutez 2>/dev/null pour les masquer.

nano — L'éditeur de texte en terminal

nano est l'éditeur le plus accessible pour les débutants. Ses raccourcis sont affichés en bas de l'écran.

nano notes.txt       # ouvre notes.txt (le crée s'il n'existe pas)

Une fois dans nano :

RaccourciAction
Ctrl + OSauvegarder (Write Out) — confirme avec Entrée
Ctrl + XQuitter (propose de sauvegarder si modifié)
Ctrl + KCouper la ligne courante
Ctrl + UColler la ligne coupée
Ctrl + WRechercher un mot dans le fichier

Cartes interactives — clique pour voir l'explication

Ctrl + O
Sauvegarder
Affiche une invite en bas avec le nom du fichier. Appuie sur Entrée pour confirmer la sauvegarde.
Ctrl + X
Quitter
Si le fichier a été modifié, nano te demande si tu veux sauvegarder (Y/N/Ctrl+C pour annuler).
Ctrl + K
Couper la ligne
Coupe la ligne entière et la met en mémoire. Peut être utilisé plusieurs fois pour couper plusieurs lignes.
Ctrl + U
Coller
Colle le contenu coupé à la position du curseur. Pratique pour déplacer des lignes.
Ctrl + W
Rechercher
Ouvre une barre de recherche en bas. Tape le mot cherché puis Entrée. Ctrl+W encore pour l'occurrence suivante.
Note

Dans nano, le symbole ^ représente la touche Ctrl. Donc ^O = Ctrl+O. Ces raccourcis sont toujours affichés en bas de l'écran dans nano.
