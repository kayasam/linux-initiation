03 — Interface graphique

Environnements de bureau Linux, GNOME, équivalences d'applications, et découverte du terminal.

L'interface graphique sous Linux

Sous Linux, l'interface graphique est un composant complètement séparé du système. Contrairement à Windows ou macOS où l'interface graphique est intégrée au cœur du système, Linux vous laisse le choix : vous pouvez installer l'interface de votre choix, ou ne pas en avoir du tout (serveurs).

Ces interfaces s'appellent des environnements de bureau.

Note
Dans cette formation, nous utilisons GNOME, l'environnement par défaut de Debian. C'est également l'environnement par défaut d'Ubuntu, Fedora et de nombreuses autres distributions.

Le dossier personnel

Sous Linux, chaque utilisateur possède un dossier personnel où sont stockés ses fichiers, sa configuration…

Windows

C:\Users\samuel\

Linux

/home/samuel/
Note
Les deux sont équivalents : c'est votre espace personnel. Vos Documents, Images, Musiques s'y trouvent. Sous Linux, on le désigne souvent par le symbole ~ (tilde). Par exemple, ~/Documents = /home/samuel/Documents. 
# Afficher le chemin du dossier personnel
echo ~
# Résultat : /home/samuel

# Aller dans le dossier personnel
cd ~
# ou simplement :
cd

Le terminal — outil central de Linux

Le terminal (aussi appelé console, invite de commandes, ou shell) est l'interface en mode texte permettant d'interagir directement avec le système via des commandes écrites.

Si l'interface graphique est pratique au quotidien, le terminal est indispensable pour l'administration Linux : il donne accès à toutes les fonctions du système, y compris celles non accessibles via les menus graphiques.

Le prompt — lire l'invite de commandes

Lorsque le terminal est ouvert, vous voyez une ligne appelée prompt. Elle vous donne des informations importantes :

samuel@debian:~$ _
Partie du promptSignification
samuelVotre nom d'utilisateur
@debianLe nom de la machine (hostname)
~Le répertoire courant (ici, votre dossier personnel)
$Vous êtes un utilisateur normal. # = vous êtes root

Premières commandes à connaître

pwd          # Afficher le répertoire courant
ls           # Lister les fichiers du dossier courant
cd Documents # Aller dans le dossier Documents
cd ..        # Remonter d'un niveau
clear        # Effacer l'écran du terminal
Tip — Module suivant
À partir du module suivant (04 — Le terminal), nous travaillerons exclusivement dans le terminal. Prenez le temps de vous familiariser avec l'ouverture du terminal et la lecture du prompt avant de continuer.
Attention — Sensibilité à la casse
Sous Linux, les noms de fichiers et commandes sont sensibles à la casse : Documents, documents et DOCUMENTS sont trois dossiers différents. Contrairement à Windows !
