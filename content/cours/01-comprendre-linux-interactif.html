Et si le logiciel appartenait à ses utilisateurs ?

Richard Stallman annonce GNU : construire un système compatible avec Unix, dont chacun peut étudier, modifier et partager les logiciels.

GNU apporte des outils. Il ne faut pas le confondre avec le noyau Linux.
À la source ↗

Des projets complémentaires. Linux n’est pas le code d’Unix renommé. GNU et Linux se rencontrent dans des distributions comme Debian.

Petite mise en situation

Gratuit = libre ?

Vous téléchargez gratuitement un logiciel. Son code est fermé et sa modification interdite. Est-il libre ?

Choisissez une réponse pour découvrir l’explication.
GPL

Les libertés voyagent avec le logiciel.

Vous distribuez une version modifiée d’un programme GPL : ses destinataires doivent conserver les droits de la GPL et pouvoir obtenir le code correspondant selon ses conditions.

Partager les libertésCode correspondant

Utiliser un programme GPL ne vous oblige pas à publier les documents que vous créez avec lui.
