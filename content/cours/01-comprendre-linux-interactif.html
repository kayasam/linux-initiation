01 — Comprendre Linux

Qu'est-ce qu'un système d'exploitation ? D'où vient Linux ? Qu'est-ce qu'une distribution ?

Qu'est-ce qu'un système d'exploitation ?

Un système d'exploitation (ou OS, de l'anglais Operating System) est le logiciel de base qui fait fonctionner un ordinateur. Il joue le rôle d'intermédiaire entre le matériel (processeur, mémoire, disque dur) et les applications que vous utilisez (navigateur, traitement de texte…).

Note — Analogie
Pensez à l'OS comme à un chef d'orchestre : il ne joue pas d'instrument lui-même, mais coordonne tous les musiciens (matériel et logiciels) pour que la musique soit harmonieuse. Sans lui, chaque instrument jouerait dans son coin.

L'histoire de Linux

En 1991, un étudiant finlandais de 21 ans nommé Linus Torvalds publie sur Internet le code source d'un nouveau noyau de système d'exploitation qu'il a écrit pour s'amuser. Il l'appelle Linux (contraction de son prénom et d'Unix, l'OS qu'il s'inspire).

Des développeurs du monde entier commencent à contribuer au projet. Trente ans plus tard, Linux est devenu le système d'exploitation le plus répandu au monde sur les serveurs, les supercalculateurs et les appareils mobiles.

Linux est partout

Tip — Linux est partout
Linux fait tourner : les serveurs Internet (Google, Facebook, Amazon…), les 500 supercalculateurs les plus puissants du monde (100 % sous Linux), les smartphones Android (Android est basé sur Linux), les objets connectés (box Internet, télévisions, routeurs…) et même la Station spatiale internationale.

Qu'est-ce que l'Open Source ?

Un logiciel est dit Open Source (ou "libre") lorsque son code source — les instructions écrites par les programmeurs — est librement accessible, modifiable et redistribuable par n'importe qui.

Note — Analogie
Imaginez une recette de cuisine. Un logiciel propriétaire (Windows, Photoshop), c'est comme un restaurant qui vous sert un plat délicieux mais refuse de vous donner la recette. Un logiciel Open Source, c'est comme un livre de cuisine partagé : vous avez la recette, vous pouvez la modifier, l'améliorer, et la partager avec d'autres.

Les avantages de l'Open Source

  • Gratuit — pas de licence à payer (le logiciel est libre, même si le support peut être payant)
  • Transparent — n'importe qui peut lire le code et vérifier ce qu'il fait vraiment
  • Sécurisé — des milliers de développeurs scrutent le code et corrigent les failles rapidement
  • Pérenne — le projet ne peut pas "mourir" comme une entreprise fermée ; le code est pour toujours public

Linux : le noyau et les distributions

Linux au sens strict désigne uniquement le noyau (le kernel) : le cœur du système qui gère le matériel. Pour obtenir un système utilisable, on ajoute autour de ce noyau :

  • Des outils système (commandes de base, scripts…)
  • Une interface graphique (optionnelle)
  • Un gestionnaire de paquets pour installer des logiciels
  • Des applications pré-installées

L'ensemble forme une distribution Linux (ou "distro"). Il en existe des centaines !

Debian — Créée en 1993, Debian est l'une des plus anciennes distributions. Elle est célèbre pour sa stabilité extrême et sa rigueur. Debian sert de base à de nombreuses autres distros (Ubuntu, Raspberry Pi OS…). Gestionnaire de paquets : apt.
Ubuntu — Basée sur Debian, Ubuntu est la distro la plus populaire pour les débutants et les postes de travail. Elle sort une nouvelle version tous les 6 mois (LTS tous les 2 ans). Très bien documentée. Gestionnaire de paquets : apt.
Kali Linux — Distro spécialisée dans la cybersécurité et les tests d'intrusion. Pré-installée avec des centaines d'outils de sécurité. Non recommandée comme OS quotidien. Gestionnaire de paquets : apt.
Rocky Linux — Alternative libre et gratuite à Red Hat Enterprise Linux (RHEL). Créée en 2021 après le changement de politique de CentOS. Très utilisée dans les entreprises pour les serveurs. Gestionnaire de paquets : dnf.

Mode graphique vs Mode texte

Sous Linux, il est possible d'interagir avec le système de deux façons radicalement différentes :

Mode graphique (GUI)Mode texte (Terminal)
InteractionSouris + clavier, fenêtres, icônesClavier uniquement, lignes de commandes
RessourcesGourmand (RAM, CPU)Très léger
PuissanceLimitée aux menus disponiblesAccès à toutes les fonctions du système
Utilisé parPostes de travail, débutantsAdministrateurs, serveurs
Note
Les serveurs Linux fonctionnent presque toujours sans interface graphique. Cela permet d'économiser des ressources (RAM, CPU) et de réduire la surface d'attaque. Un serveur web n'a pas besoin de fenêtres ni de curseur de souris pour servir des pages web !
