08 — Gestion des paquets

apt, dpkg, dépôts — installer et maintenir des logiciels sur Debian/Ubuntu

Paquets et dépôts

Un paquet est une archive contenant un programme, ses dépendances, ses fichiers de configuration et des scripts d'installation. Le gestionnaire de paquets s'occupe de tout installer au bon endroit.

Analogie Imaginez un meuble IKEA : le paquet contient toutes les pièces + la notice. Le gestionnaire de paquets (apt) est le livreur qui va chercher la boîte à l'entrepôt (le dépôt), puis assemble tout pour vous.

Le dépôt

Un dépôt est un serveur officiel qui héberge des milliers de paquets. La liste des dépôts est configurée dans /etc/apt/.

cat /etc/apt/sources.list          # dépôts principaux
ls /etc/apt/sources.list.d/         # dépôts supplémentaires

La chaîne d'installation

ÉtapeOutilRôle
1dépôtServeur distant stockant les paquets
2aptTélécharge, résout les dépendances, installe
3dpkgOutil bas niveau qui décompresse et installe réellement
4/etc/apt/Configuration des dépôts (sources.list)

apt — le gestionnaire de paquets

Les 3 étapes fondamentales — cliquez pour détailler

Étape 1
sudo apt update
Mettre à jour la liste
Étape 2
sudo apt install nom
Installer un logiciel
Étape 3
sudo apt upgrade
Mettre à jour les logiciels
Cliquez sur une étape pour voir les détails.
Important apt update NE met PAS à jour les logiciels installés — il met à jour uniquement la liste des versions disponibles dans les dépôts. C'est comme actualiser le catalogue avant de commander.

Toutes les commandes apt — cliquez pour détailler

update

sudo apt update
Met à jour la liste des paquets disponibles depuis les dépôts. À faire avant tout install ou upgrade.

upgrade

sudo apt upgrade
Met à jour tous les logiciels installés vers leur dernière version. Nécessite un apt update préalable.

install

sudo apt install vim curl git
Installe un ou plusieurs paquets et leurs dépendances. On peut lister plusieurs paquets séparés par des espaces.

remove

sudo apt remove vim
Supprime le programme mais conserve les fichiers de configuration. Utile si vous voulez réinstaller plus tard avec la même config.

purge

sudo apt purge vim
Supprime le programme ET les fichiers de configuration. Nettoyage complet.

autoremove

sudo apt autoremove
Supprime les paquets installés automatiquement (dépendances) qui ne sont plus utiles. À lancer après un remove/purge.

search

apt search editeur-texte
Cherche un paquet par mot-clé dans les noms et descriptions. Pas besoin de sudo pour chercher.

show

apt show vim
Affiche les informations détaillées d'un paquet : version, description, dépendances, taille.

list --installed

apt list --installed
Liste tous les paquets actuellement installés sur le système. Souvent combiné avec | grep nom pour filtrer.

dpkg — installation de fichiers .deb

Parfois, un logiciel n'est pas dans les dépôts officiels. Son éditeur met à disposition un fichier .deb à télécharger directement depuis son site.

apt vs dpkg dpkg est l'outil de bas niveau qui installe réellement les fichiers. apt est une surcouche de dpkg qui ajoute la gestion des dépôts, la résolution automatique des dépendances et une interface plus conviviale.

Installer un fichier .deb

# Télécharger le fichier depuis le site de l'éditeur
wget https://example.com/logiciel.deb

# Installer le fichier .deb
sudo dpkg -i logiciel.deb

# Si des dépendances manquent, les résoudre avec apt :
sudo apt -f install

Vérifier si un paquet est installé

sudo dpkg -l | grep vim     # cherche vim dans la liste
dpkg -l nom-paquet          # statut d'un paquet précis

Commandes dpkg utiles

CommandeDescription
sudo dpkg -i fichier.debInstalle un paquet .deb local
sudo dpkg -r nomSupprime un paquet (conserve la config)
sudo dpkg -P nomSupprime le paquet + configuration (purge)
dpkg -lListe tous les paquets installés
dpkg -L nomListe les fichiers installés par un paquet
dpkg -S /chemin/fichierTrouve quel paquet a installé un fichier

Séquences type à connaître

Installer un logiciel

sudo apt update
sudo apt install nom-du-logiciel

Maintenance régulière du système

sudo apt update && sudo apt upgrade
sudo apt autoremove
Astuce Le && enchaîne deux commandes : la seconde ne s'exécute que si la première a réussi. C'est une bonne pratique pour update + upgrade.

Logiciels utiles à installer en formation

sudo apt install curl git htop tree net-tools vim

# curl      : télécharger des fichiers/URLs
# git       : gestion de versions
# htop      : moniteur système interactif
# tree      : afficher l'arborescence en arbre
# net-tools : commandes réseau (ifconfig, netstat…)
# vim       : éditeur de texte avancé

Rechercher avant d'installer

apt search editeur-texte   # cherche par mot-clé
apt show vim               # infos détaillées sur un paquet
apt list --installed       # voir ce qui est déjà installé
