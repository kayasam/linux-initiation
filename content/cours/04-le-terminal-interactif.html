Module 04

Le Terminal

Prendre le contrôle de Linux en ligne de commande

Pourquoi utiliser le terminal ?

Le terminal permet de :

  • Automatiser des tâches répétitives (scripts)
  • Administrer un serveur distant sans interface graphique
  • Opérer sur des centaines de fichiers en une seule commande
  • Diagnostiquer des problèmes système en profondeur
Note — Analogie

L'interface graphique, c'est comme acheter des plats préparés : pratique mais limité. Le terminal, c'est cuisiner soi-même : plus de travail au départ, mais un contrôle total sur le résultat.

Attention

Linux est sensible à la casse : ls ≠ LS ≠ Ls. Utilise toujours les minuscules pour les commandes.

Se repérer et se déplacer

pwd — Print Working Directory

Affiche le chemin absolu du dossier où tu te trouves actuellement.

$ pwd
/home/stagiaire

ls — Lister le contenu

ls            # liste simple
ls -l         # liste détaillée (permissions, taille, date)
ls -a         # affiche aussi les fichiers cachés (commençant par .)
ls -lh        # liste détaillée avec tailles lisibles (Ko, Mo)
ls /etc       # liste le contenu du dossier /etc

cd — Changer de répertoire

cd /etc           # aller directement dans /etc (chemin absolu)
cd ..             # remonter d'un niveau dans l'arborescence
cd                # retourner dans son dossier personnel (~)
cd ~/Documents    # aller dans Documents dans le dossier personnel
cd -              # retourner dans le dossier précédent
Astuce

La touche Tab complète automatiquement les noms de fichiers et de dossiers. Tape les premières lettres puis appuie sur Tab — Linux fait le reste !

Chemin absolu vs relatif

Chemin absolu

Commence toujours par /. Il décrit le chemin complet depuis la racine du système, quel que soit le répertoire courant.

/home/stagiaire/Documents/rapport.txt
/etc/apt/sources.list
/var/log/syslog

Chemin relatif

Part du répertoire courant. Il n'y a pas de / au début. Son sens change selon où tu te trouves.

Documents/rapport.txt     # si tu es dans /home/stagiaire
../autre-dossier          # remonter puis entrer dans autre-dossier
./script.sh               # le fichier script.sh dans le dossier courant
TypeCommence parExempleSignification
Absolu//home/stagiaireDepuis la racine, toujours valide
Relatifnom ou ../DocumentsDepuis le dossier courant
Personnel~/~/DocumentsRaccourci pour /home/utilisateur
Bonne pratique

Dans les scripts, préfère toujours les chemins absolus pour éviter les surprises selon le dossier courant.

Lire le contenu des fichiers

CommandeUsage
cat fichierAffiche tout le fichier d'un coup
less fichierAffichage page par page (q pour quitter, ↑↓ pour naviguer)
head fichierAffiche les 10 premières lignes
head -n 20 fichierAffiche les 20 premières lignes
tail fichierAffiche les 10 dernières lignes
tail -f fichierSuit le fichier en temps réel (journaux)
 
cat /etc/hosts             # affiche le fichier hosts
less /var/log/syslog       # parcourir les journaux (q pour quitter)
tail -f /var/log/syslog    # surveiller les logs en direct

Obtenir de l'aide

man ls         # manuel complet de la commande ls
ls --help      # aide rapide intégrée
Note

man ouvre le manuel officiel intégré au système. Pour naviguer : Espace = page suivante, q = quitter. C'est la référence la plus complète et toujours disponible hors ligne.

Raccourcis clavier essentiels

Clique sur une carte pour voir plus de détails.

Tab
Complétion automatique
Complète noms de fichiers, dossiers et commandes. Double-Tab affiche toutes les possibilités.
↑ / ↓
Historique des commandes
Navigue dans les commandes précédentes. Évite de tout retaper.
Ctrl + C
Interrompre une commande
Arrête immédiatement le programme en cours d'exécution. Indispensable si quelque chose se bloque.
Ctrl + L
Effacer l'écran
Nettoie le terminal (équivalent de la commande clear). L'historique reste intact.
Ctrl + A
Début de ligne
Déplace le curseur au début de la ligne en cours de saisie.
Ctrl + E
Fin de ligne
Déplace le curseur à la fin de la ligne en cours de saisie.
history
Liste les commandes passées
Affiche les dernières commandes avec leur numéro. Tape !42 pour relancer la commande numéro 42.
