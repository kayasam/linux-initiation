**A1.**
```bash
pwd
# /home/stagiaire
```

**A2.**
```bash
ls
ls -l
```

**A3.**
```bash
cd /etc
pwd
# /etc
```

**A4.**
```bash
cd ..
pwd
# /
```

**A5.**
```bash
cd /var/log
ls
```

**A6.**
```bash
cd        # sans argument = dossier personnel
# ou
cd ~
```

**A7.**
```bash
cat /etc/hostname
head -5 /etc/passwd
```

**A8.**
```bash
less /etc/hosts
# Flèches haut/bas pour naviguer, q pour quitter
```

**A9.**
```bash
ls --help
```

**A10.**
```bash
history | tail -10
```
